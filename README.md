# TERSEY · дуэль

Нативный macOS-терминал «дуэль»: сразу **два окна-панели** — один ввод, и Claude и
Codex отвечают параллельно, а третий арбитр (haiku) сравнивает ответы и объявляет
победителя. Чаты с историей (`~/.terseylite/chats.json`), восстановление при запуске.
Один Swift-файл + куб на arm64-ассемблере. Бинарник ~276 КБ.

## Сборка

```sh
./build.sh
```

Поставит `~/Applications/TerseyDuel.app` (подпись ad-hoc; свой сертификат: `IDENTITY=... ./build.sh`).

Ключей внутри нет: перед запуском дочерних CLI вычищаются `ANTHROPIC_API_KEY`,
`OPENAI_API_KEY` и родственные переменные — работает только подписочный логин
установленных `claude` / `codex`.

Требования: macOS 14+, Xcode CLT, установленные CLI `claude` и/или `codex`.
